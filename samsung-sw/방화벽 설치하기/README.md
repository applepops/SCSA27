**[문제이해 및 구상]**
- 많이 풀어본 유형의 bfs 문제라는 생각이 들어 마음이 편해졌음.
- 그러나 걸리는 점은 3개의 방화벽을 골라야 한다는 점인데 시간이 터지지는 않을까 약간 걱정이 되었지만 워낙에 n과 m이 작아서 시간복잡도를 고민하지는 않아도 되겠다고 판단했음.
- 백트래킹으로 3개를 고를까 3중 for문을 돌려서 고를까 고민하다가 for문이 더 단순할 것 같아 후자 선택.
- 빈칸의 개수가 무조건 3개 이상이라는 언급이 있어서 이상한 엣지 케이스는 없겠거니 판단함.
- 할 일을 나누어서 생각했음: 먼저 방화벽이 들어갈 곳 3군데를 고른다 -> 고른 데를 기준으로 불을 퍼트려본다. -> 불이 붙지 않은 곳을 구한다 -> 이걸 반복하여 max값을 구한다.

**[구현]**
- 과정평가에서 3개 뽑기할 때 많은 분들이 실수했던 range 문제를 조심하려고 노력했음.
- 처음에는 매번 새로 3개를 뽑을 때마다 2차원 배열을 copy해서 3개를 추가할까 했는데 주소 참조가 안되게 2차원 배열을 복사하는 방법이 생각이 안 나서; 그냥 추가하고 다시 지우고 하는 방식을 선택했는데 결과적으로 메모리는 아꼈다고 생각하지만 2차원 배열을 복사하는 방법 좀 익히자고 생각했다.
- 그 외는 그렇게 구현하기에 까다롭다고 느낀 부분이 있지는 않았음.

성공.


**[잘한 점]**
