# [자율주행 자동차](https://www.codetree.ai/frequent-problems/samsung-sw/problems/autonomous-driving)

**SW 역량 테스트** › 2017 상반기 오후 1번 문제

개인코드리뷰 <br/>
260818 자율주행 자동차

코드길이: 주석 포함해서 71줄 <br/>
메모리: 17MB <br/>
수행시간: 72ms

13:50 ~ 14:15 문제이해 및 구상 <br/>
14:15 ~ 14:41 구현 <br/>
14:42 오픈 테케 돌려봄 -> 실패 <br/>
14:46 디버깅해서 해결 <br/>
14:52 문제 제출 -> 성공

**[문제이해 및 구상]**
- 처음에 전진과 회전을 구분하지 못하여 혼란스러웠음. 문제를 몇 차례 더 읽어보고 나서 구분시킴.
- 총 면적을 구하라는 부분을 통해서 visited를 활용한 bfs로 풀어야겠다고 생각했음.
- 첫 위치를 총 면적에 포함해야 한다는 부분을 보고 조심해야겠다고 생각했음.
- 좌표가 0-based로 주어진다는 것을 파악했음.
- 주어진 규칙들을 분기문별로 손정리를 해서 큐에서 뽑고 나서 어떤 식으로 if-else문을 활용해서 나눌지 구상했음.
- 방향전환을 할 때 방향벡터에서 -1 처리를 통해 좌회전을 하게 해야겠다고 구상했음.

**[구현]**
- 큐에서 뽑은 뒤 처리 후 큐에 넣을 때 현재방향을 무엇으로 넣어야 하는지 잠시 헷갈렸음.
- 방향벡터에서 -1해줄 때 %4를 하면 되는 건지 잠시 헷갈려서 간단한 식 돌려보면서 직접 확인함.
- 동쪽하고 서쪽하고 좀 헷갈림; 맞게 해놓고 틀린 줄 알고 몇 번을 점검함.
- 후진하는 경우는 손구상에서 별 생각이 없었어서 구현할 때 -2처리하면 된다는 걸 다시 구상함.
- 분기문마다 조건을 다 위에 글로 작성했음. 이러면 좀 덜 헷갈리는 기분이 든다.
- 그 외에는 크게 어려운 점이 없이 구현했음.

**[오픈 테케 돌려봄 -> 실패]**
- 실패를 해서 당황했지만 그냥 오픈 테케가 왜 2가 나오는지 천천히 디버거로 확인해보자 싶었음.
- 코드 흐름을 따라가다보니 좌회전 후 전진을 할 때에 dir_cnt를 0으로 초기화해주지 않았음을 깨닫고 바로 수정하고 다시 돌려보니 됐음.
- 다른 곳 틀렸을 까봐 다른 오픈 테케로 돌려보면서 내가 생각한 대로 차가 움직이는지 한 번 더 검증하고 제출함.

성공.


**[잘한 점]**
- 주어진 규칙들을 분기문별로 손정리한 것이 잘한 점이라고 생각함. 애벌레나 톱니바퀴 문제 등에서 손정리 제대로 안하고 일처리 순서를 뒤바꾸거나 time을 이상하게 더해주거나 해서 디버깅도 잘 안되고 답도 일부만 맞고 할 때가 많았는데 이번에는 일처리 순서 및 분기문을 확실히 손구상에서 잡고 갔다고 생각함.

**[못한 점]**
- 나는 동쪽과 서쪽이 왜 헷갈릴까? E와 W는 안 헷갈리는데..
- 다른 사람들 코드에 비해 실행시간이 15ms 정도 긴 편인 것 같은데 왜 차이가 나는지 궁금하다.
