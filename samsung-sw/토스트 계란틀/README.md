# [토스트 계란틀](https://www.codetree.ai/frequent-problems/samsung-sw/problems/toast-eggmold)

**SW 역량 테스트** › 2018 하반기 오전 2번 문제

개인코드리뷰 <br/>
260820 토스트계란틀

코드길이: 주석 포함 약 80줄  <br/>
메모리: 24MB  <br/>
수행시간: 200ms

16:15 ~ 16:36 문제이해 및 구상  <br/>
16:36 ~ 16:58 구현  <br/>
16:58 ~ 17:05 검증  <br/>
17:05 문제 제출 -> 성공 

**[문제이해 및 구상]**
- 문제를 읽고 한 5분 정도 지났을 무렵 전형적인 bfs 문제라는 판단을 했음.
- 혹시나 무한히 계란이 이동하는 경우는 없을까 하고 걱정을 한참 하기 시작함.
- 따라서 혹시 무한 루프를 돌지도 모르니 문제에서 주어진 2000회라는 최대 계란 이동 횟수를 코드에 보험으로 포함시키기로.
- 이외에도 L과 R이 같은 경우나 L이 1이고 R이 100인 경우 등 엣지가 될 수 있는 경우를 생각하느라 대부분의 시간을 씀.
- 그 외에는 bfs가 전형적인 템플릿이 있다보니 코드 구상까지 구체적으로 잡지 않음.

**[구현]**
- bfs는 너무 익숙해서 구현이 어렵지 않았음.
- 다만 visited 조건 확인할 때 자꾸 0과 1을 반대로 적어서 중간중간 오타 집어내긴 했음. -> 자주 하는 실수?

**[검증]**
- 구상할 때 걱정했던 무한루프의 문제가 진짜 발생하는지 직접 엣지를 만들어보고자 하였음.
- 그러나 대부분 0이나 1이 결과가 나왔고 2 이상이 답으로 나오는 엣지를 생각해내는 것부터 어려웠음.
- 그리고 오히려 소숫점을 버리다보니 기존에 걱정했던 무한루프는 없을 것 같다는 생각도 함.

성공.

**[잘한 점]**
- 문제 여러 번 읽고 예제를 손으로 따라하며 정확히 흐름을 이해하는 루틴을 지켰음.

**[못한 점]**
- 아직까지 엣지 케이스를 만들어내는 능력이 부족한 것 같음.
