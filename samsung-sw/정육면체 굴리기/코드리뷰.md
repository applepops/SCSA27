개인코드리뷰 <br/>
260906 정육면체 굴리기

코드길이: 주석 포함 약 50줄 <br/>
메모리: 17MB <br/>
수행시간: 66ms

문제이해 및 구상 (15분 이상) <br/>
구현 (10분) <br/>
오픈테케 -> 실패 <br/>
디버깅 (25분) <br/>
문제 제출 -> 성공

**[문제이해 및 구상]**
- 문제를 다 이해하고 나서 코드를 구상하자는 규칙을 잘 지킴.
- 정육면체의 이동의 기준을 정육면체의 위치 idx, 즉 위, 아래, 왼, 오른, 앞, 뒤로 두고
- 어차피 경우의 수는 4개밖에 안되니까 하드코딩.
- 위치의 경우 1-based로 주어지길래 딕셔너리 활용하기로.

**[구현]**
- 정육면체 굴리는 문제는 저번에도 풀어보기도 했고 이건 난이도도 쉬워서 금방 구현함.
- 그런데 오픈테케 돌려보니 답이 틀림

**[디버깅]**
- 이유를 찾으려는 대장정이 시작됨.
- 이동방향에 따라 예시 dice를 만들고 움직이고 나서의 dice 상태를 찍어봤는데 이상하게 나옴.
- 알고보니 구상단계애서 계산한 idx가 엉망이었던 것. 그림을 그리면서 천천히 했어야 했는데
- 이미 풀어본 문제라는 자신감으로 idx 계산을 제대로 안해서 동서 바꿔쓰고 남북도 바꿔쓰고 난리.

**[잘한 점]**
- 오류를 찾아냈다. 생각보다 좀 걸리긴 했지만.
- 나는 분명히 틀렸다라는 마음가짐으로 여유를 두고 찾으면 되려 잘 찾아지고
- 마음이 급하고 안절부절 못하면 오류는 더 안 보이는 법.

**[못한 점]**
- idx 계산 잘 못하는 거 알면서 더블 체크 안하고 들어간 것.
- 입체 나오면 그림 그려가면서 차분히 하자.
