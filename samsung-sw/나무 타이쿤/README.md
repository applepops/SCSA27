**[문제이해 및 구상]**
- 2차원 배열만 보면 bfs 생각이 나서 또 bfs 생각을 함. 결과적으로 아니었음.
- 격자의 모든 행과 열이 끝과 끝이 연결되어 있다길래 과정평가 때 풀었던 어린왕자 문제가 생각남.
- 영양제는 이동할 때 격자가 연결되어 있는데 리브로수가 성장할 때는 격자를 벗어나면 안된다는 것을 주의하려 함.
- 특수 영양제를 큐로 관리하고 싶다고 생각함. 나는 큐를 사랑한다.
- 대략적인 자료구조만 정한 후에 거대한 M년이라는 for문 안에 1년마다
  특수 영양제 좌표 이동/1씩 성장/주변 살펴서 추가 성장/나무 잘라서 다시 영양제 만들기를 순서대로
  반복해야겠다고 대략적으로 코드 흐름을 그림으로 그렸음.
- 이때까지는 진짜 문제에 제시된 걸 다 안 놓치고 다 구상에 넣은 줄로 착각함.

**[구현]**
- 코드 흐름을 거의 미리 다 짜두었기 때문에 코드 짜는 데서 헤매지는 않았음.
- 그런데 방향을 딕셔너리로 관리하고 싶었는데 딕셔너리 get 함수 쓰려니 자꾸 오류가 나서 결국 if문으로 처리
- 여기서 1차적으로 약간 멘탈이 흔들리고 심장이 뛰기 시작했음.
- 그리고 나서 다 짰다 싶어서 1번 테케 돌려 봤는데 답이 안 나왔음.

**[1차 디버깅]**
- 다행히 문제 예시로도 주어진 가시적인 부분에서 조건을 빼먹은 것이었기에 print문을 통해 금방 실수를 발견할 수 있었음.
- 빼먹은 조건은 '해당 년도에 특수영양제 맞은 땅을 제외'하고 나무를 잘라야 한다는 부분.
- 그런데 두 번째 테케부터 또 값이 이상하게 나와서 심장이 빠르게 뛰기 시작.

**[2차 디버깅]**
- 끔찍한 시간이었음.
- 시간적 압박이 심하게 다가와서 멘탈을 다잡기가 굉장히 어려웠음.
- 어디서부터 의심을 해야할지 감이 안 와서 좌표부터 한 줄 한 줄 모든 것을 다 의심하기 시작함.
- 끝나기 5분 전쯤 자포자기 상태로 코드를 가만히 들여다보다가
- 지금의 코드는 현재 영양제 좌표에서 1을 더하고 바로 대각선 나무 확인하고를 반복한다는 것을 깨달음.
- 이것은 분명 문제에서 알려준 부분과는 다른 부분이었고 1을 한 번에 모든 영양제 좌표에 다 더해준 뒤
  대각선 나무 살피기에 들어가야 한다는 것을 번개 맞듯이 깨달아버리고 바로 코드 변경해서 2분 전 제출.

성공.

**[잘한 점]**
- 끝까지 포기하지 않은 점은 칭찬하고 싶음.
- 그리고 시간 안에 논리적인 오류를 찾아내서 다행이라고 생각함.

**[못한 점]**
1. 딕셔너리 사용법을 제대로 익히고 있지 않다는 것.
- 사용하는 자료구조가 한정적이고 쓰던 것만 쓰던 버릇이 심함.
- 지난 번 스터디에서 승현님이 딕셔너리를 잘 쓰시는 걸 보고 오늘 해보고 싶었는데 안되니 멘탈이 흔들렸던 것이 큼.
- 그깟걸로 멘탈이 도대체 왜 흔들렸는지 모르겠음.
- 뭘 몰랐는지 살펴보니 딕셔너리 선언이 잘못되었음.
2. 문제의 세세한 조건들을 유심히 검증한 뒤 코드를 짜지 않은 것.
- 코드를 구상할 때 조건을 두 개나 빼먹었음.
- 통탄할 노릇임.
- 코드 흐름을 1차적으로 다 구상하고 나서 문제를 읽으면서 빠짐없이 넣었는가 체크하는 과정을 추가해야할 듯함.
3. 객체지향적인 코드를 짜지 않은 것.
- 함수를 좀 활용해서 흐름을 탁탁 나뉘게 했으면 덜 헷갈리지 않았을까 싶음.
- 큰 for문 안에서 모든 과정을 다 처리하려니 디버깅이 오래 걸렸던 것 같음.
- 할 일이 오늘처럼 많은 문제는 할 일별로 함수를 짜려고 노력해보자.
